# Техническая спецификация

## Назначение

Сервис принимает DOCX, создаёт безопасный HTML через GPT Astra 6, позволяет просматривать документ, выполнять AI-правки и переводить текст, хранит версии и публикует самодостаточный HTML.

## Основные требования

- исходный DOCX хранится в Timeweb S3;
- фоновые задания выполняются PostgreSQL worker;
- prompt и PDF-образец стилизации выбираются из опубликованной версии стиля;
- HTML проходит строгую проверку разрешённых тегов, атрибутов и URL;
- изображения сохраняются отдельно и материализуются только при публикации;
- каждая правка создаёт новую ревизию с проверкой `base_revision`;
- документы и задания доступны только владельцу;
- HTML-просмотрщик работает в изолированном iframe;
- перевод изменяет только текстовые сегменты и сохраняет структуру HTML.

## Пользовательские сценарии

- загрузка одного или нескольких DOCX;
- выбор опубликованной стилизации;
- просмотр структуры документа по ссылкам оглавления;
- AI-предложение изменений и его принятие;
- перевод на выбранный язык;
- просмотр и восстановление ревизии;
- HTML-публикация и отзыв публикации;
- создание и редактирование профилей стилизации.

## Проверки

Backend: `compileall`, unit-тесты и проверка направлений импортов. Frontend: TypeScript, ESLint, проверка границ и production-сборка. Финальная проверка запускается через Docker Compose.
